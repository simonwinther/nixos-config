# November 2026 audit

Audit of both repositories and the running `lambda` system, carried out on
16-17 November 2026. All changes are uncommitted in this repository and in
`dotfiles/`. Most of them take effect only after Simon's next switch, and the
zram and kernel changes after the reboot that follows it. Validation results
are in [VALIDATION.md](VALIDATION.md#november-audit-integration--2026-11-17).

## Scope and method

The work was split into 20 areas: NixOS system, Home Manager packages, user
services, flake and rebuild workflow, third-party packages, desktop bar,
Desktop Ring, search and clipboard, `desktopctl`, cluster and Hendrix, dictation,
pickers and transfer, Neovim and editors, shell and terminal, Hyprland and
appearance, browser and applications, media and OBS, portable scripts, security,
and tests and quality.

For each area:

1. An auditor measured the live system read-only (journal, `hyperfine`,
   closure graphs, `strace`, cargo-audit) and recorded findings with evidence,
   a proposal, a risk and a test plan.
2. Two reviewers checked every finding independently, one for functionality
   and one for value, re-measuring where they could. They voted approve,
   modify or reject. Only findings both accepted were implemented, with the
   reviewers' modifications applied.
3. Work already in progress before the audit was assessed in the same way and
   either completed, fixed or reverted.
4. An integration pass applied the cross-area edits, updated the trackers, and
   validated the result statically, by evaluation and by building packages and
   checks. Nothing was activated, and no toplevel or activation package was
   built.

In total: 210 findings, 70 implemented, 54 in-progress items resolved, 86
recommendations left for Simon, and 54 cross-area items. Of the cross-area
items, the global compinit, dictate's rustls-webpki, LLMNR and four test-gate
fixes were applied during integration.

### Background load and memory

- `desktop-mako` restart loop: a stray D-Bus-activated mako made the unit
  restart every 2 s, about 7.8% of a core and 38,700 failed starts per day. The
  unit now gives up after five failures in 30 s. The stray process still needs
  a one-time cleanup; see the recommendations.
- zram raised from 25% to 50% of RAM with zram-tuned VM settings (swappiness
  180, page-cluster 0, watermark tuning). zram was full (3.41 GiB compressed to
  843 MiB), and the kernel OOM killer fired 3 times in 12 boots.
- `twingate-dns-guard`: one D-Bus read replaces `ip`, `resolvectl status` and
  `grep`; 17.3 ms to 5.5 ms CPU per check (-68%), about 570 ms to 200 ms per
  minute.
- `desktopctl` process supervisor: 148.6 to 0 wakeups per second per live
  clipboard owner.
- User units no longer embed unrelated store paths, so rebuilds stop
  restarting 11-12 running desktop services.
- tmux `status-interval` 10 to 60 s: about 13 s CPU and 3,000 process starts
  less per attached client-hour.
- forest-green lock screen: no per-second shell clock (about 0.75% of a core
  while locked) and none of the six config errors per lock.
- Project picker sync: 360 to 120 syncs per hour with three ChatGPT windows.
- Duplicate binding and double reload fixes: `makoctl invoke` once per press,
  one Hyprland reload per touchpad key, one monitor reconciliation per hotplug.

### Reliability and correctness

- cluster: an interrupted helper upload no longer installs a truncated agent
  that breaks every later call; the integration suite passes fully (73/74 at
  HEAD).
- `ku-vpn` DNS check works (`getent` was missing from its PATH).
- Calculator input with deeply nested parentheses no longer aborts the whole
  search and clipboard service.
- Clipboard search finds entries when a query word is punctuation only.
- file-picker schema recovery works again under rusqlite 0.43.
- OBS: a refused sync no longer aborts the desktop's Home Manager activation,
  and the launcher starts OBS when defaults cannot be applied.
- `nixos-rebuild-desktop activate` works while the build window waits for
  Enter; `times` charts nh-only histories; `build-times` no longer panics on
  reload.
- Tailscale SSH, the keyboard-recovery path, is declared on `lambda`.
- Session oneshots have start timeouts; git `unstage`, `last` and `hist`
  aliases work; zsh reloads no longer stack Atuin strategies; the Nautilus
  LocalSend item appears and no longer blocks every right-click.
- Test gates: `desktop-behavior` passes in lambda's real sandbox (5 failures
  at HEAD), `dotfiles-parity` uses an explicit allowlist of Home Manager
  overrides, `hyprland-config` parses lambda's generated Lua, and the
  portable-syntax check shellchecks 69 scripts.

### Security

- Lock refresh from nixpkgs 2026-10-15 to 2026-11-15: kernel 6.18.63, Chromium
  157, Tailscale 1.104.5 and a CA bundle without the distrusted emSign G3 root.
  It takes effect at the next switch.
- dictate uses rustls-webpki 0.103.17 (RUSTSEC-2026-0382).

- Roblox type definitions come from a commit-pinned URL.

  a CVE-2026-119375 fix for the binary, which links the system SQLite.

## Recommendations not applied

Ordered by priority. "Reviewers" summarizes the two independent votes.

### 1. Security: Simon's action first

1. **Gmail app password in public dotfiles history** (critical). An aerc
   `accounts.conf` with an IMAP/SMTP app password was committed in 8c82231
   and deleted in e907bf1; both commits are public. Revoke the app password
   and review account activity since 2026-08-05. Reviewers: both approve.
   Rotation is the fix; a history rewrite is optional and would break the
   submodule commits recorded in this repository's history.
2. **OpenWeatherMap key in public dotfiles history** (7692e60,
   `waybar/weather.py`). Generate a new key, delete the old one, and write it
   (mode 0600) to `~/.config/desktop/secrets/weather-key`. Reviewers: both
   approve.
3. **Postgres published on 0.0.0.0 and [::]:55432.** The `gods-eye-db`
   TimescaleDB container from an opencode compose project accepts
   connections on Wi-Fi and the tailnet with a password equal to its
   user/database name. Docker's DNAT bypasses the NixOS firewall. Publish it
   on `127.0.0.1:55432:5432`, recreate it, and rotate the password with
   `ALTER ROLE`. Reviewers: both modify. One notes that `ip = "127.0.0.1"` in
   the daemon settings covers only the default bridge, not compose networks;
   the other would add `default-network-opts` `host_binding_ipv4` as well. A
   systemic guard needs live testing.
4. **Plaintext credentials in `$HOME`.** `~/.git-credentials` is unused
   (git uses `gh`): revoke its token and delete it. Narrow the `gh` token's
   scopes, and move the Hetzner root password to key-only login. Reviewers:
   both modify; storing the KU TOTP seed beside the password is a design
   decision, not a quick fix.
5. **Docker group is root-equivalent** for every process running as simon,
   including coding agents. Options: rootless Docker, `sudo docker`, or
   documenting the choice. Reviewers: report only; never apply automatically.
6. **No guard against committing credentials.** Reviewers disagree: one
   wants a `checks.secret-scan` that excludes vendored trees, the other only
   narrow `dotfiles/.gitignore` globs, with a pre-commit scanner left to Simon.
7. **canvas-mcp 1.12.0** has high-severity advisories fixed in 1.16.0, but
   every later release needs FastMCP 4, which nixpkgs lacks. Do not wire it
   into an MCP client until it is upgraded. Reviewers: both modify.

### 2. Blockers and high impact

1. **nordvpn-tui's source archive is gone** upstream and the pending lock
   would rebuild it. Resolved by removing nordvpn-tui (no longer used); the
   NordVPN service itself stays.
2. **Stray mako cleanup.** Stop the D-Bus-activated mako that owns
   `org.freedesktop.Notifications` once, so `desktop-mako` can take over.
   Reviewers: both approve.
3. **Locking never turns the panel off**: `desktopctl` still calls legacy
   `hyprctl dispatch dpms`, which Hyprland 0.56's Lua config rejects (31
   errors in 7 days). Use `hl.dsp.dpms`. Elephant's `symbols.toml` has the same
   legacy `sendshortcut` problem. Reviewers: both approve.
4. **`desktop-power-profile` fails at every boot** because of an ordering
   cycle with power-profiles-daemon. Reviewers: both approve.
5. **TSC watchdog**: after S3 resume, `lambda` falls back to HPET in 7 of 12
   boots, which makes clock reads cost 1.24 µs instead of about 20 ns. Add
   `tsc=nowatchdog` in `hosts/lambda/default.nix`. Reviewers: both modify. One
   found that 2 of 12 boots had a real 0.74% TSC miscalibration that the
   watchdog would no longer catch. Never fall back to `tsc=reliable`.
6. **systemd-oomd watches nothing.** Reviewers split. One would enable user
   slices with `ManagedOOMMemoryPressure` forced to `auto` on `user.slice`
   after the zram reboot. The other rejects it: a kill on the root-owned
   `user.slice` ignores per-unit preferences and could end the whole graphical
   session. Revisit after running with 50% zram.
7. **Neovim never enables the packaged language servers** (clangd, nil,
   marksman, bashls and others) on NixOS. Reviewers: approve and modify; enable
   clangd now and decide on the rest.
8. **`pass -c` passwords are stored in clipboard history.** Patch pass to
   copy with `wl-copy --sensitive`. Reviewers: approve and modify.
9. **Transcoding**: GIFs keep every frame in RAM (about 5 GB per minute at
   1080p), photos lose EXIF orientation, and videos keep GPS metadata.
   Reviewers: both approve each.
10. **Hyprland 0.57.2** cannot be adopted yet: Simon's Hyprspace fork pins
    efb5099 and must be ported first.
11. **`desktopctl` Rust port.** An earlier plan to port all of desktopctl
    (about 8,000 lines) was not started. This audit cut its startup by 58% and
    removed the hot-path spawns, but each call still costs about 55 ms, and
    held media keys start one Python process per repeat (up to 50/s).
    Reviewers modified the media-key item. Decide first on the unshipped
    `desktop_control/` copy (2,698 lines; reviewers: both modify).

### 3. Worth deciding

- **texliveFull** instead of the deprecated, uncached `texlive.combined`,
  plus `texliveFull.info`. Reviewers: both modify.
- **Hyprland on the system nixpkgs** (`follows`): about 1.6 GiB of duplicate
  libraries. Reviewers: modify and reject; it would lose the Hyprland cachix
  hits and contradicts the deliberate Mesa decision in 027f1fa.
- **NordVPN and Docker start at boot** (about 1.4% of a core idle). Reviewers:
  both modify; `norduserd` re-activates `nordvpnd` at login.
- **OBS on lambda** uses the desktop's NVENC profile (2.56 GiB, mostly CEF).
  Reviewers: both modify; a neutral host-scope decision.
- **file-picker scopes**: the stale `--all` index costs 442.6 MiB, and Ctrl+S
  over `/` would index about 2.8M store files (likely OOM). Reviewers: both
  modify.
- **breakd overlay panics on every break**, a one-line tokio fix best landed
  upstream. Reviewers: both approve.
- **Home Manager activation** spends about 14 s per switch on per-file
  processes. Reviewers: report only.
- **Root HEAD pins a dotfiles commit that is not on its remote**, so a
  root-only push breaks rev-pinned evaluation. Reviewers: both modify.
- Smaller items with two approvals: notch clock stale for up to 60 s after
  resume, Ring volume steps flatten channel balance, umask 077 for launched
  apps, night light never tints, launcher icons missing for 10 of 13 entries,
  `dictation-volume-duck` amplifies above 1, `mariadb-libs` installs the full
  server, playwright-cli has no executable, the stale vendored
  `pkgs/hyprspace/source`, and the extension test suites running in no check.

### Rejected by both reviewers

PAM keyboard-interactive in sshd (wrong premise), the NordVPN polkit rule,
mixed glibc in the bar, Motion sampling, the Hendrix gateway probe, file-picker
wrapper layers and refresh stat cost, a power-saving look variant, and the
systemd-boot editor.
